# GSAP smooth slider

A pinned, scroll-driven full-screen slider. Scrolling moves through the slides, each title animates in line by line with SplitText, and Lenis smooths the scroll.

**Live:** [animation-gsap-smooth-slider.vercel.app](https://animation-gsap-smooth-slider.vercel.app)

**Stack:** HTML, CSS, vanilla JavaScript, GSAP (ScrollTrigger, SplitText), Lenis

**Run it:** `npx serve .` and open the printed URL.

A practice piece for scroll-driven animation.
